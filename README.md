## ✨ Features & Motion Design

- **Pure Vanilla Stack:** Zero dependencies, zero build step, zero frameworks. Instant load times (~25 KB total payload).
- **Default Dark Mode:** True OLED black (`#000000`) by default, persisting user preferences in `localStorage`.
- **View Transitions API Ripple:** Circular clip-path portal wave expanding from the toggle button on theme switch, paired with spring-physics icon morphing (`cubic-bezier(0.34, 1.56, 0.64, 1)`).
- **Smart Sticky Navigation:** Navbar glides out of view when scrolling down and reappears with frosted-glass backdrop blur on scroll up.
- **Scroll-Snap Carousel:** Mobile-friendly, touch-swipeable track for competitions and hackathons with desktop arrow controls.
- **Interactive Radial Spotlight:** Dynamic ambient mouse-following radial mask over the subtle background dot grid.
- **Accessibility & Performance:** Semantic HTML5, full `prefers-reduced-motion` fallbacks, WCAG AAA color contrast ratios, and dynamic mobile browser `theme-color` meta updates.
